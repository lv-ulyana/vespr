# Vespr — Flutter (iOS і Android з одного коду)

Приватний щоденник побачень. Усі дані тільки на телефоні: без акаунта, без сервера, без ШІ.

> Важливо: цей код написаний без можливості скомпілювати його. Під час розробки не було доступу до Flutter SDK і pub.dev.
> Логіку перевірено окремо (така сама логіка працює в Expo-версії), а Dart-код перечитано вручну.
> Перший `flutter run` може показати дрібні помилки компіляції. Кинь їх мені текстом, і я виправлю.

## Перший запуск (Mac)

1. Встанови Flutter: https://docs.flutter.dev/get-started/install/macos. Потрібна версія 3.27 або новіша.
   Для Android — Android Studio, для iPhone — Xcode.
2. Розпакуй архів і в Терміналі з папки `vespr_flutter` виконай:
   ```bash
   bash tool/setup.sh
   ```
   Скрипт створить папки `android/` та `ios/` і налаштує їх:
   - відбиток пальця;
   - minSdk 23;
   - відкриття календаря;
   - тексти дозволів iOS.
3. Підключи телефон кабелем (на Android увімкни «Налагодження USB») або запусти емулятор і виконай:
   ```bash
   flutter run
   ```
4. Тести логіки запускаються командою `flutter test`.

## Що вміє

- **Онбординг:** 18+, ім'я і дата (знак і аркан), «з ким зустрічаєшся», PIN, перша людина.
- **PIN і відбиток / Face ID.** Блокування лежить поверх будь-якого екрана. Через 30 секунд у фоні апка блокується знову.
- **Записи:**
  - «Як пройшло?» і «Був секс?»;
  - 3 базові питання + твої;
  - прапорці з підказками з нотатки за ключовими словами;
  - теги-осі, факти, «Ти сама».
- **Люди:** картка, висновки за шаблонами, метч арканів і зодіаку, минулі з причиною, Зала ганьби.
- **Мапа:** ефекти тегів з порогами «Схоже / Закономірність / Точно», формула вечора.
- **Календар:** записи крапкою, заплановані зустрічі кільцем, «Нова зустріч» (людина, день, час, місце, нагадування).
- **Експорт** (Налаштування → Записи → Експорт, безкоштовно для всіх):
  - **Таблиця CSV.** «Зустрічі» (рядок на запис) або «Люди» (рядок на людину). Період, «Без імен» (№1, №2), нотатки і «Чутливе» — за перемикачами. Відкривається в Excel, Google Таблицях і Numbers.
  - **Календар.** Одна запланована зустріч відкривається одразу у вікні створення події календаря. Кілька зустрічей або вся історія експортуються файлом `.ics`.
  - Тиха назва «✦ Vespr» стоїть за замовчуванням, нагадування за годину. Сталі UID: повторний імпорт оновлює події, а не дублює.
- **Таблиця записів** (Люди → значок таблиці, або Налаштування → Записи): усі записи рядками, фільтр по людині, сортування за датою чи оцінкою, тап відкриває запис.
- **Імпорт** (Налаштування → Записи → Імпорт), без ліміту безкоштовної версії:
  - **З таблиці CSV.** Роздільник «;», «,» чи Tab і кодування (UTF-8 або Windows-1251 з Excel) вгадуємо самі. Стовпці зіставляються за назвою, кожен можна перепризначити. Обов'язкові: дата, людина, оцінка 1–5. Таблицю з нашого ж експорту впізнаємо повністю. Нові люди створюються, дублі (людина + дата + оцінка) і криві рядки пропускаємо з номером рядка. Файл .xlsx не читаємо — просимо зберегти як CSV.
  - **З календаря.** Календар телефону (пакет `device_calendar`, тільки читання) або файл `.ics`. Людину вгадуємо за ім'ям у назві події з відмінками («з Марком»), місце — за словами «бар», «кіно», «кава». Майбутні події стають запланованими зустрічами, минулі — зустрічами, що чекають оцінки (картка «Лишилось оцінити» на головній). Повторний імпорт тієї ж події не дублює.
- **Wrapped:** генератор за правилами, міні-Wrapped, «Варто помітити» тільки для неї, 3 слайди безкоштовно.
- **Резервна копія:** файл, зашифрований AES-256-GCM (ключ з пароля через PBKDF2), і відновлення з нього.
- **Ліміти безкоштовної версії:** 5 записів на місяць, 3 людини. «Тестовий Premium» у налаштуваннях.

## Чого ще нема

- Оплата в Google Play і App Store (наступний крок: RevenueCat або in_app_purchase).
- Голосовий запис з розшифровкою (логіка прапорців з тексту вже є: `lib/logic/triggers.dart`).
- Нагороди, порівняння двох людей, поширення слайдів Wrapped у сторіз, гайд.
- Тексти для «вона».

## Де що лежить

- `lib/data/catalog.dart` — питання, теги, прапорці з тригерами, факти, місця, ліміти.
- `lib/data/models.dart`, `lib/data/store.dart` — дані і збереження (один JSON у SharedPreferences).
- `lib/logic/` — уся аналітика (`stats`), Wrapped (`wrapped`), експорт (`export`), імпорт (`import_csv`, `import_ics`), астро, шаблони речень.
- `lib/services/` — PIN, файли, календар телефону, резервна копія.
- `lib/screens/` — екрани. `lib/ui/` — кольори, шрифти, компоненти з дизайну.
- `assets/fonts/` — Prata, Raleway, Onest, Cormorant Garamond (ліцензія OFL, вшиті в апку).

Дизайн експорту — ряд «13. Експорт», таблиці й імпорту — ряд «14. Таблиця та імпорт» на полотні «Vespr — дизайн апки».

На Android `tool/setup.sh` додає дозволи READ_CALENDAR і WRITE_CALENDAR: пакет календаря просить обидва одним вікном «Календар». Vespr у календар сам нічого не пише — додавання зустрічі йде через системне вікно календаря.


## Веб-версія і автозбірка на GitHub

`.github/workflows/build.yml` після кожної зміни в гілці `main`:
1. проганяє `flutter analyze` і `flutter test`;
2. збирає веб-версію і викладає її на GitHub Pages: `https://<нік>.github.io/<репозиторій>/`;
3. збирає APK для Android: Actions → останній запуск → Artifacts → `vespr-android-apk`.

Щоб Pages запрацювали: Settings → Pages → Source: **GitHub Actions**. Безкоштовно Pages працюють для публічного репозиторію; для приватного потрібен GitHub Pro (студентам безкоштовно через GitHub Education).

У веб-версії вимкнене те, чого браузер не вміє: Face ID / відбиток (лишається PIN), читання календаря телефону (лишається імпорт файлу .ics), вікно «додати в календар» (замість нього файл .ics). Файли експорту відкриваються через «Поділитися» або просто завантажуються. Дані зберігаються в браузері (localStorage) і нікуди не відправляються. Сторінка має `noindex`, тож пошуковики її не показують.
